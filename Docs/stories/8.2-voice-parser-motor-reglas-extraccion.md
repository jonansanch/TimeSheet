# Story 8.2: VoiceParser — Motor de Reglas de Extracción

Status: done

## Story

As a empleado,
I want que el sistema entienda lo que dije y extraiga automáticamente los campos del formulario,
So that no tenga que tipear cada campo manualmente después de dictar.

## Acceptance Criteria

1. **Given** transcript con "hoy", **When** se ejecuta el parser, **Then** Fecha = fecha actual. "ayer" → fecha actual menos 1 día. "anteayer"/"antier" → fecha actual menos 2 días.

2. **Given** transcript con fecha explícita como "primero de junio del 2026" o "quince de marzo", **When** se ejecuta el parser, **Then** Fecha queda asignada al valor correspondiente (año actual si no se especifica).

3. **Given** transcript con "de 8 a 12" (primer par), **When** se ejecuta el parser, **Then** HoraEntradaAM = 08:00, HoraSalidaAM = 12:00.

4. **Given** transcript con "de 1 a 5 de la tarde" o segundo par de horas menor a 8, **When** se ejecuta el parser, **Then** HoraEntradaPM = 13:00, HoraSalidaPM = 17:00.

5. **Given** transcript con nombre de cliente normalizado (sin tildes, minúsculas) que coincide con un cliente del catálogo, **When** se ejecuta el parser, **Then** Cliente queda asignado con el valor exacto del catálogo.

6. **Given** cliente detectado y nombre de proyecto en transcript, **When** se ejecuta el parser, **Then** Proyecto queda asignado con el valor exacto del catálogo del cliente.

7. **Given** keyword "presencial", "remoto" o "híbrido"/"hibrido" en transcript, **When** se ejecuta el parser, **Then** Modalidad queda asignada al valor correspondiente del catálogo.

8. **Given** keyword de recurso en transcript (orden de especificidad descendente), **When** se ejecuta el parser, **Then** Recurso queda asignado al valor del catálogo.

9. **Given** keyword de lugar en transcript, **When** se ejecuta el parser, **Then** Lugar queda asignado al valor del catálogo.

10. **Given** texto que sigue a "descripción:" o "descripcion:" en transcript, **When** se ejecuta el parser, **Then** Descripcion = ese texto (trimmed).

11. **Given** uno o más campos no detectados, **When** el parser termina, **Then** `VoiceParseResult.CamposNoDetectados` lista los nombres en español de los campos faltantes **según el estado real del formulario** (no del último utterance).

## Dev Notes

- `NumberWords` extendido hasta 31 incluyendo "primero"/"primer", "veintidós"→"veintidos" (sin tilde tras normalize), "treinta y uno".
- `FechaExplicitaRegex`: `(\d{1,2})\s+de\s+(mes)\s*(?:del?\s+(\d{4}))?` — opera sobre texto ya normalizado.
- `ComputeCamposFaltantes()` lee el estado real del formulario en lugar de `r.CamposNoDetectados` para soportar dictado en múltiples frases sin marcar como faltantes campos ya llenos por utterances anteriores.
- `VoiceParser` es puro (sin efectos secundarios, sin async) — registrado como Singleton.
- No hay cambios al backend en esta story.
