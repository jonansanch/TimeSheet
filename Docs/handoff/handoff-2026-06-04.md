## Arquitectura

### Backend — `Backend/src/`

```
Backend/src/
├── Api/                    → Minimal APIs, endpoints, mediarow middleware
│   ├── DependencyInjection.cs
│   ├── Endpoints/Auth.cs, Bitacora.cs, Clientes.cs, Dashboard.cs, ...
│   └── Program.cs
├── Application/            → CQRS (Commands/Queries con MediatR)
│   └── Features/
│       ├── Catalogos/Clientes/
│       ├── Empleados/
│       ├── Login/
│       ├── RegistrosHoras/
│       ├── SolicitudesExcepcion/
│       ├── Users/
│       └── ...
├── Domain/                 → Entidades, invariantes, enums
└── Infrastructure/
    ├── Data/               → EF Core DbContext, DapperTypeHandlers
    ├── Identity/           → IdentityService (Dapper)
    ├── Dashboard/          → DashboardRepository (Dapper queries)
    └── DependencyInjection.cs
```

Patrones clave:
- **CQRS**: Commands (escritura) + Queries (lectura) via MediatR
- **Two-layer auth**: endpoint + AuthorizationBehavior en pipeline MediatR
- **Read stack**: Dapper para dashboards/reportes (EF Core solo para escritura)
- **Output cache**: 60s en endpoints de dashboard, varía por query string

### Frontend — `Fronted/src/WebUI/`

- Blazor WebAssembly (.NET 10) + MudBlazor
- Componentes Kpg* en Feature folders (Admin, Registro, Dashboard, ...)
- Layout: MainLayout.razor + NavMenu.razor + KpgShiftForm.razor
- PWA: manifest + service worker
